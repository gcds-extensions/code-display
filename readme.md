# Component display

A proof of concept web component to replace the use of stroybook on the [GC Design System documentation site](https://github.com/cds-snc/gcds-docs).

This component uses the [GC Design System](https://design-system.canada.ca/en/).

## Features

The `gcds-ext-code-display` component features:

- code preview
- attributes tab
- slots tab
- events tab
- accessibility tab
